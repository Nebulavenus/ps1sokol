# Session Changelog: Engine Overhaul & Phase 1-2 Implementation

## 1. Major Architectural Refactoring
* **Module Decomposition**: Deconstructed the monolithic `src/main.nim` (>1300 lines) into a modular architecture to improve maintainability and keep files under the 500-line limit.
    * `src/types.nim`: Centralized data structures and state definitions.
    * `src/math_utils.nim`: Optimized math helpers and ray-triangle intersection logic.
    * `src/colors.nim`: Inline color packing/unpacking for Sokol formats.
    * `src/aobaker.nim`: Isolated Ambient Occlusion baking and Uniform Grid acceleration logic.
    * `src/mesh_loader.nim`: Dedicated OBJ/PLY loading and GPU resource allocation.
    * `src/physics.nim`: Extracted camera logic and collision detection.
    * `src/culling.nim`: New visibility testing logic.

## 2. Phase 1: Engine Hardening & Optimization
* **Spatial Partitioning**: Replaced brute-force collision raycasting with a **Uniform Grid** lookup. This significantly reduces the number of triangle tests per frame for both road-height detection and barrier collisions.
* **Frustum Culling**: Implemented AABB visibility checks for track segments. The engine now skips draw calls for meshes that are behind the camera or out of view.
* **Resource Management**: Added a `ResourceManager` to track GPU handles. Implemented a `clearResources` system to ensure all buffers and textures are properly destroyed on cleanup, preventing memory leaks.

## 3. Phase 2: Visual Fidelity & FX
* **Custom Sprite Shader**: Developed `sprite.glsl` featuring:
    * **Vertex Jitter**: Authentic PS1-style "wobble" by snapping NDC coordinates.
    * **Affine Texture Mapping**: Perspective-incorrect UVs for that retro aesthetic.
    * **Alpha Blending**: Support for transparency and discard-based masking.
* **Blob Shadows**: Added procedurally generated, ground-aligned shadow quads that follow the car's position and orientation.
* **Retro Particle System**:
    * **Volumetric Smoke**: Particles use a multi-blob organic texture and randomized rotation to feel less "flat."
    * **Sub-stepped Emission**: Implemented path-interpolation to fill gaps in drift smoke trails at high speeds.
    * **Exhaust FX**: Added continuous low-rate smoke emission from the car's exhaust.
    * **Transparency Sorting**: Particles are sorted by distance from the camera every frame to ensure correct alpha blending.
* **Post-Processing Pass**:
    * Implemented an offscreen rendering architecture.
    * Developed `postfx.glsl` providing **CRT Scanlines** and **Color Depth Reduction** (4-bit per channel feel).
    * Integrated a warm color-grading tint.

## 4. Bug Fixes & Refinements
* **Fog Correction**: Fixed a bug where particles turned blue at certain distances by moving fog calculations to view-space depth instead of local vertex distance.
* **UV Correction**: Fixed an inverted camera/UI display by flipping screen quad UV coordinates.
* **Rendering State**: Resolved an issue where the car model became invisible due to incorrect pipeline state retention.
* **Billboard Logic**: Fixed degenerate transformation matrices in particle rendering by correcting the camera-facing forward vector.
