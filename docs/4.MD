# Ambient Occlusion Baking & Advanced Material Systems

## Overview
This document covers the evolution of the Ambient Occlusion (AO) system from simple CPU baking to a high-performance, GPU-driven material mixer using Bent Normals.

## 1. The AO Baking Pipeline
To achieve a retro look with depth, we implemented a pre-computation step for mesh data.

### Ray-Casting Algorithm:
- **Hemisphere Sampling**: Rays are cast from each vertex to check for occlusion.
- **Uniform Grid Acceleration**: Optimized the bake from O(N²) to near-linear time by only checking triangles in local spatial grid cells.
- **Binary Caching**: Baked results are saved to `.baked_ao.bin` to skip re-computation on subsequent runs.

## 2. GPU-Driven Material Mixer
By passing a raw AO value (or Bent Normal) to the shader, we enabled real-time artistic control.

### Layered Blending Order:
1. **Base Color**: The starting texture/vertex color.
2. **Shadows (Multiply)**: Darkens the base based on `ao` and `u_aoShadowStrength`.
3. **Environment Tint (Blend)**: Blends toward a `u_aoBaseColor` in unoccluded areas.
4. **Dirt/Grime (Detail)**: Adds a `u_aoDetailColor` to the most occluded crevices.

### Gradient Remapping (Redesign 3):
Using `smoothstep` in the fragment shader allows for sharp or soft "dirt" transitions:
```glsl
float dirt_factor = smoothstep(u_aoDirtRange.x, u_aoDirtRange.y, v_ao);
final_color = mix(final_color, u_aoDetailColor, dirt_factor * u_aoDirtStrength);
```

## 3. Directional AO (Bent Normals)
Upgraded the scalar AO to a 3D vector representing the "main open direction."

### Vertex Data Change:
```nim
type Vertex = object
  pos, normal: Vec3
  color: uint32
  uv: Vec2
  bentNormal: Vec3 # Replaced 'ao: float32'
```

### Lighting Model:
- **Occlusion**: `1.0 - length(v_bentNormal)`
- **Hemisphere Lighting**: The `v_bentNormal` direction is used to blend between `u_skyColor` and `u_groundColor`, faking global illumination without real-time rays.
- **Contrast Control**: Added `pow(occlusion, u_aoContrast)` to recover shadow depth lost to the additive sky lighting.
