# QOI Nim Implementation History

## Overview
This document summarizes the development of a pure-Nim QOI (Quite OK Image) loader and writer, its integration with `sokol-nim`, and key debugging milestones.

## 1. Pure Nim Implementation (Standard Library Only)
The initial requirement was to remove external dependencies like `binstreams`.

### Key Components:
- **`ByteStream`**: A custom wrapper for `seq[byte]` to handle pointer-based reading/writing.
- **Header Parsing**: Manual Big-Endian handling for `uint32` fields (`width`, `height`).
- **Memory Management**: Optimized using `cast` for zero-copy conversion between `string` and `seq[byte]`.

### Corrected File I/O:
```nim
proc readQOI*(filename: string): QOIF =
  let fileStream = newFileStream(filename, fmRead)
  if fileStream == nil: raise newException(IOError, "Cannot open: " & filename)
  defer: fileStream.close()
  let qoiData = cast[seq[byte]](fileStream.readAll())
  return decodeQOI(qoiData)

proc writeQOI*(filename: string, header: Header, pixelData: seq[byte]) =
  let qoiData = encodeQOI(header, pixelData)
  writeFile(filename, cast[string](qoiData))
```

## 2. Testing & Bug Fixes
The test suite from `nimQOI` was adapted. A `ValueError` ("Test Dimensions may encounter a one byte limit") was identified in the `fillRGBArray` helper.

- **Issue**: The check `if x * x > 31` was too restrictive for a 16x16 test.
- **Fix**: Reverted to `if x > 5` to ensure unique values without byte-wrap in the blue channel (`i * 8 < 256`).

## 3. Sokol-Nim Integration
Loading QOI data into Sokol textures requires matching the `sg_pixel_format`.

### RGB to RGBA Conversion
Since many Sokol backends (WebGL/GLES2) do not support `RGB8`, a conversion layer was implemented:
```nim
var finalPixels: seq[byte]
var format: sg_pixel_format

if qoi.header.channels == 3:
  format = SG_PIXELFORMAT_RGBA8
  finalPixels = newSeq[byte](qoi.header.width * qoi.header.height * 4)
  for i in 0 ..< (qoi.header.width * qoi.header.height).int:
    finalPixels[i*4 + 0] = qoi.pixels[i*3 + 0]
    finalPixels[i*4 + 1] = qoi.pixels[i*3 + 1]
    finalPixels[i*4 + 2] = qoi.pixels[i*3 + 2]
    finalPixels[i*4 + 3] = 255
else:
  format = SG_PIXELFORMAT_RGBA8
  finalPixels = qoi.pixels
```

## 4. Debugging: The "Diagonal Pattern" Glitch
A visual artifact appearing as diagonal lines and color shifts was diagnosed as a **Stride Error**.

- **Cause**: The code was performing an RGB->RGBA conversion on data that was **already** RGBA. 
- **Effect**: Each pixel read was shifted by 1 byte (reading Alpha as Red, Red as Green, etc.), creating a cumulative skew.
- **Resolution**: Ensure the conversion loop only runs when `header.channels == 3`.
