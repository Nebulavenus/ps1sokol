# PS1 Racing Game Framework: Physics & Audio

## Overview
This document outlines the transition from a static PS1-style renderer to a functional arcade racing game, focusing on vehicle dynamics and procedural audio.

## 1. Arcade Vehicle Physics
The physics system was redesigned from direct position manipulation to a force-based "Arcade" model.

### Core Mechanics:
- **Velocity & Torque**: Input applies forces (`engineForce`, `turningTorque`) rather than changing position/rotation instantly.
- **Tire Grip (Vector Alignment)**: Simulates friction by slowly lerping the velocity vector toward the car's forward facing direction.
- **Drifting**: Triggered by a "drift" button which reduces the `grip` multiplier, allowing for lateral sliding while increasing `turningTorque`.

```nim
# Drift Logic Snippet
let currentGrip = if state.input.drift: grip * driftGripMultiplier else: grip
let currentVelocityDir = if len(state.player.velocity) > 0.1: norm(state.player.velocity) else: forwardDir
let newVelocityDir = lerp(currentVelocityDir, forwardDir, currentGrip * dt)
state.player.velocity = newVelocityDir * len(state.player.velocity)
```

## 2. Procedural Engine Audio
Using `sokol-audio` in a "push" model, we generate engine sounds in real-time.

### Engine Synthesis:
- **Harmonic Stack**: Combines 3 sawtooth oscillators (Fundamental, 2x, 3x frequencies).
- **Dynamic RPM**: Frequency is mapped to car speed: `freq = idleFreq + (speed * freqPerRpm)`.
- **Tire Screech**: High-frequency tone (1200Hz + jitter) mixed with 40% white noise, activated during drifts.

### Audio Presets:
- **Classic Arcade**: High frequency per RPM, fast attack on screech.
- **Beefy Muscle**: Low base frequency, higher weight on the fundamental harmonic.
- **Sporty Whine**: Stronger upper harmonics for a "buzzier" high-rev feel.

## 3. Player Controls (Default)
- **W / S**: Accelerate / Brake (Reverse)
- **A / D**: Steering
- **Space / LShift**: Drift
- **Esc**: Quit
- **Mouse**: (If Free Cam is enabled) Look around
