# PS1 Era Emulation & Engine Development (Nim/Sokol)

## Overview
This document covers the research into PlayStation 1 graphics techniques and the subsequent implementation of a 3D engine in Nim using the Sokol library.

## 1. PS1 Graphics Techniques & Emulation
The "PS1 Look" is defined by hardware limitations that can be emulated in modern shaders.

### Core Techniques:
- **Affine Texture Mapping**: Linear UV interpolation without perspective correction.
- **Vertex Jitter**: Quantizing vertex positions to a low-resolution grid (e.g., 240x240) in the vertex shader to simulate fixed-point precision.
- **Ordered Dithering**: Using a 4x4 Bayer matrix to simulate higher color depth on a 15-bit (RGB555) framebuffer.
- **Point Sampling**: Disabling texture filtering for a pixelated look.
- **Distance Fog**: Used for atmosphere and to mask limited draw distances.

## 2. Technical Milestones

### Corrected Dithering Shader (GLSL)
The dithering logic must add a bias *before* quantization to effectively smooth gradients:
```glsl
vec3 quantize_and_dither(vec3 color, vec2 screen_pos) {
    const float levels = 32.0; // 5 bits per channel
    const mat4 bayer = mat4(
        0.0, 8.0, 2.0, 10.0,
        12.0, 4.0, 14.0, 6.0,
        3.0, 11.0, 1.0, 9.0,
        15.0, 7.0, 13.0, 5.0
    ) / 16.0;

    int x = int(mod(screen_pos.x, 4.0));
    int y = int(mod(screen_pos.y, 4.0));
    float dither = bayer[x][y] - 0.5;

    // Add dither bias before rounding to 'levels'
    return floor(color * (levels - 1.0) + dither + 0.5) / (levels - 1.0);
}
```

## 3. Engine Features
- **FPS Camera**: Uses `sapp.lockMouse(true)` and mouse deltas to update Yaw/Pitch.
- **Coordinate System**: Implements a standard 3D look-at system with WASD movement.
- **Asset Pipeline**: Loads PNG textures via `stb_image` and applies them to custom-parsed OBJ meshes.
